# Small tools. Less friction.

I’m **alvinfunborn**. I build open-source tools for the things that keep getting in the way of everyday work — finding the right AI conversation, navigating a busy desktop, or knowing which language I’m about to type.

**[Explore my projects →](https://alvinfunborn.github.io/)**

### Attend — find the task, pick up the thread

A local console for AI coding sessions. Organize work with **tags and custom labels**, follow session trees and comments, and see what needs your attention across multiple coding agents.

[Website & interactive tour](https://alvinfunborn.github.io/attend/) · [Source](https://github.com/alvinfunborn/attend) · [Getting started](https://github.com/alvinfunborn/attend#quick-start)

### Screen Buoy — your keyboard, your whole desktop

Navigate **Windows and macOS** with letter hints across multiple monitors. Click, scroll, and drag from the keyboard, with configurable hint styles and key bindings.

[Website & demos](https://alvinfunborn.github.io/screen-buoy/) · [Source](https://github.com/alvinfunborn/screen-buoy) · [Downloads](https://github.com/alvinfunborn/screen-buoy/releases/latest)

### DynCursor — know the language before the first letter

A **Windows** utility that changes the mouse pointer with the active keyboard layout and IME state. See the input-state cue where you’re looking, with custom cursors, settings, and tray controls.

[Website & setup guide](https://alvinfunborn.github.io/DynCursor/) · [Source](https://github.com/alvinfunborn/DynCursor) · [Downloads](https://github.com/alvinfunborn/DynCursor/releases/latest)
